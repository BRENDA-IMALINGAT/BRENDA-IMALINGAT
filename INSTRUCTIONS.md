## ⚙️ GitHub Actions – Snake Animation Setup

The snake SVG is auto-generated by `.github/workflows/main.yml`.  
It runs **every 12 hours** and also **on every push to `main`**.

### One-time setup (do this once):

1. Go to your GitHub repo → **Settings** tab → **Actions** → **General**
2. Under **Workflow permissions**, select **Read and Write permissions** → click **Save**
3. Go to the **Actions** tab → click **Generate Snake** → click **Run workflow**

> ✅ After this first manual run, the snake updates automatically every 12 hours.

## ✏️ How to Update Your README

### Change your name or typing animation text
Edit **line 4** of `README.md`:
```html
<img src="https://readme-typing-svg.herokuapp.com/?font=Righteous&size=35&center=true&vCenter=true&width=500&height=70&duration=4000&lines=Hi+There!+👋;+I'm+Brenda+Imalingat!" />
```
- Replace `I'm+Brenda+Imalingat!` with your own text
- Spaces must be `+` in the URL
- Multiple lines are separated by `;`

### Change your bio
Edit **line 6**:
```html
<h3 align="center">A passionate Dev , Network Engineer and  Data Scientist from Uganda</h3>
```

### Change your email
Edit **line 15**:
```html
<a href="mailto:bimalingat5@gmail.com">
```
> Always keep the `mailto:` prefix — without it the link won't open an email client.

### Change your LinkedIn
Edit **line 18**:
```html
<a href="https://www.linkedin.com/in/imalingat-brenda-439b14300/" target="_blank">
```

### Add or remove skill icons
Edit **lines 28–29**. Browse available icon names at [skillicons.dev](https://skillicons.dev):
```html
<img src="https://skillicons.dev/icons?i=react,vue,tailwind,html,css,figma,vscode,github,git,bootstrap" /><br/>
<img src="https://skillicons.dev/icons?i=nodejs,express,firebase,supabase,mysql,python,figma,js" /><br/>
```
- Icons are comma-separated, no spaces
- Keep each row to ~10–12 icons for best display

### Add more social links
Copy an existing badge block and update the `href` and badge URL:
```html
<a href="https://twitter.com/yourhandle" target="_blank">
  <img src="https://img.shields.io/badge/Twitter-1DA1F2?style=for-the-badge&logo=twitter&logoColor=white" />
</a>
```
Browse all available badges at the [Shields.io Badges repo](https://github.com/alexandresanlim/Badges4-README.md-Profile).

## 🚀 Pushing Changes to GitHub

After editing, commit and push:
```bash
git add README.md
git commit -m "Update README"
git push origin main
```

Your GitHub profile updates instantly after the push. The snake animation also regenerates on push. ✅
